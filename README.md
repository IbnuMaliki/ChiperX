# CipherX — Cryptography Suite

Website enkripsi & dekripsi berbasis algoritma kriptografi klasik.

## Algoritma yang Didukung
- Caesar Cipher
- Vigenère Cipher
- Columnar Transposition Cipher

## Cara Jalankan Lokal

```bash
pip install -r requirements.txt
python app.py
```

Buka: http://localhost:5000
